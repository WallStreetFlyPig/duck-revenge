# 一只鸭子的复仇

> 昨天，他们把你赶出了喷泉。今天，你带了朋友。

**[在线游玩：一只鸭子的复仇](https://wallstreetflypig.github.io/duck-revenge/)** · [GitHub 源码](https://github.com/WallStreetFlyPig/duck-revenge)

简体中文 · 电脑键盘 · 2D 俯视角 · TypeScript + Vite + Canvas 2D。

![游戏预览](media/preview.png)

本包包含完整源码、已构建的 `dist/`、测试与本地静态服务。游戏无需账号或后端，没有外部素材、在线字体或统计收集。`docs/` 是用于 GitHub Pages 的静态发布目录。

## 立即游玩

**Windows：双击「启动游戏.cmd」**，保持窗口开启，然后用浏览器打开：

**http://127.0.0.1:4173**

启动器优先使用已安装的 Node.js；本机没有全局 Node 时会尝试使用 Codex 随附的运行环境。若两者都不存在，需先安装 Node.js，或使用其他静态服务器托管 `dist/`。

也可以在本目录执行：

```sh
node serve.mjs
```

已有 Python 的电脑也可以执行：

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

直接游玩构建产物**不需要安装开发依赖**。不要直接双击 `index.html`；请使用本地静态服务。关闭服务窗口或按 Ctrl+C 即停止。端口冲突时关闭旧服务，或设置 `PORT` 为其他端口。

推荐 1280×720 或更大的浏览器窗口；支持 1920×1080。离开窗口会自动暂停，返回后点击「继续行动」或按 Esc。没有手机触控操作。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 八方向移动，斜向不加速 |
| 空格 | 冲刺 0.6 秒，发动时开始计算 3 秒冷却；可转向；站立时沿最后朝向 |
| 按住 E | 在午餐旁静止 0.6 秒偷取；移动、松开或离开范围会取消 |
| 按 E | 喂食招募伙伴，或在喷泉内开始最终挑战 |
| Q | 260 范围内吸引人类、召回已抵达集合点的伙伴，冷却 2 秒 |
| Esc | 暂停 / 继续 |
| F3 | 开关调试：碰撞、视野、路径、帧率 |

## 完整一局

1. 从西南池塘出发，按屏幕指引找到教学长椅。偷取会让主人惊讶，然后追赶你。
2. 累计偷三份午餐。背包最多三份；可以提前喂食伙伴，任务进度会保留。
3. 探索草坪、餐车广场与花园，招募豆豆、饼饼、团团、点点、大白，每只消耗一份食物。
4. 用冲刺、转弯和带小鸭标记的窄缺口甩开追兵。树篱、树干和喷泉雕塑遮挡视线。午餐 20 秒补货，不会永久耗尽。
5. 伙伴受惊会跑到池塘、草坪或花园集合点。靠近 260 范围按 Q 免费召回。撤离途中暂不能召回；召回后有三秒保护。
6. 全部招募后，把至少三只跟随伙伴带进中央喷泉。**继续向浅水区深处走**，让后面的伙伴也进入，再按 E 开始。
7. 在喷泉内绕雕塑移动，维持自己和至少三只伙伴在区域内，累计占领 15 秒。条件不足先暂停，两秒后开始倒退；状态栏会解释原因。
8. 胜利后查看成绩和纪录，或再来一局。被抓三次则本局结束。

前两次被抓会清空携带食物、重置喷泉挑战，并送回池塘；累计偷取与招募进度保留，伙伴在池塘重新集合。恢复过场不计入游戏时间。

本地保存最高**通关**分数、最佳通关时间、声音和减少动态效果设置。失败不会覆盖通关纪录。设置或存储失效时仍可正常玩。不同端口、浏览器或清除站点数据会形成新的本地纪录。

## 源码与构建

开发与测试推荐 **Node.js 24 或更新版本**。

```sh
npm install
npm run dev
npm run build
npm test
```

也可使用随包锁文件：

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm test
```

`npm run build` 先做 TypeScript 严格检查，再生成 `dist/`。Vite 使用 `native` 配置加载方式，避免在受限 Windows 环境中由配置打包器扫描父目录。依赖固定为 Vite 7.3.6、TypeScript 5.9.3、Playwright 1.62.1；游戏运行不依赖 Playwright。

浏览器回归测试：先运行 `node serve.mjs`，再在另一个终端执行 `npm run test:browser`。脚本使用 Windows 标准安装路径的 Chrome 和 Edge，无需下载测试浏览器；其他安装路径可修改 `tests/browser.mjs` 底部路径。测试结果写入 `reports/`。测试需要关闭占用相同端口的其他网站。

移动追逐压力测试可运行 `npm run test:performance`，使用同一本地服务。此测试在内存中禁止抓捕结算、保护伙伴，以持续测量完整追逐与渲染；正常游玩规则不受影响。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `src/config.ts` | 主要速度、范围、冷却、地图互动点配置 |
| `src/world.ts` | 固定地图、分步碰撞、视线、网格 A* 与错峰寻路 |
| `src/game.ts` | 固定时间步状态、玩家、人类、鸭群、任务、计分、胜负 |
| `src/input.ts` | 键盘、按住交互、失焦清理 |
| `src/render.ts` | 原创程序绘制地图、角色、粒子、镜头、调试覆盖层 |
| `src/main.ts` / `src/style.css` | 中文菜单、HUD、成绩、本地运行循环 |
| `src/audio.ts` | 本地合成音效、背景音乐、限流与静音 |
| `src/storage.ts` | 带版本的本地设置与纪录、损坏容错 |
| `tests/` | 逻辑、完整单局与浏览器测试 |
| `TEST-REPORT.md` | 实际测试方法、结果、限制 |
| `dist/` | 可直接静态托管的完整成品 |
| `serve.mjs` | 仅绑定本机回环地址的静态服务 |

正常 URL 不暴露调试对象。开发时添加 `?debug` 可供浏览器测试访问当前模拟状态；这是本地页面内的诊断开关，没有 HTTP 调试接口或后台服务。

## GitHub Pages 发布

仓库的 Pages 发布源使用 `main` 分支下的 `/docs` 目录。修改游戏后运行 `npm run build:pages`，提交并推送更新的源码和 `docs/`。页面使用相对资源路径，可在仓库子路径中运行；`.nojekyll` 保留原始静态文件。

## 本版调校与限制

- 保留说明中的玩家、游客和保安速度、冲刺与叫声冷却、偷取时间、资源上限、占领 15 秒等主要数值。
- 冲刺期间允许转向，便于连续转弯；无无敌效果，仍会碰撞和被抓。
- 鸭子半径 12、玩家 13、人类 25，保证 48 单位缺口仅鸭子可通行。伙伴正常跟随 202、落后时 265 单位/秒；首次加入也给予三秒受惊保护。
- 对无法到达的最后目击点设置 12 秒调查上限，之后搜索四秒再返回，避免人类永久卡在缺口外。
- 尚未组织 3—5 位首次玩家试玩，**5—8 分钟典型局长与三次内通关率未验证**。已知地图的自动路径操作能明显更快，不应把它当作真人体验数据。
- Firefox 未实测；当前电脑已安装的 Chrome 和 Edge 已验证。音乐与音效已验证生成、开关和容错，未进行主观听感评审。
- 程序形状插画与合成音频为第一版完整表现，不含外部角色图集、录制配音、多地图或手机适配。
